# Legacy.Daanse REPO

> **Status: Deprecated / Migration in progress**

This repository is the original clone repository of the (Mondrian fork)[https://github.com/pentaho/mondrian]. Over time, the codebase was split into separate repositories to establish clearer ownership and responsibilities.

The main components have been moved to the following repositories:

https://github.com/eclipse-daanse/org.eclipse.daanse.sql/

https://github.com/eclipse-daanse/org.eclipse.daanse.mdx/

https://github.com/eclipse-daanse/org.eclipse.daanse.olap/

https://github.com/eclipse-daanse/org.eclipse.daanse.rolap/

https://github.com/eclipse-daanse/org.eclipse.daanse.rolap.mapping/

Only some of remaining integration tests are still located in this repository.

## Planned Archival

The remaining integration tests will be migrated to the **Rollap repository** over the next few weeks.

Once this migration is complete, this repository will be archived. It will remain available only for historical reference and to preserve the original repository history.

## No Further Development in This Repository

Please continue all new development in the appropriate successor repositories.

**Pull requests and issues submitted to this repository will no longer be processed**, as the code contained here is no longer current.

For changes, bug reports, and new features, please use the corresponding successor repository.
